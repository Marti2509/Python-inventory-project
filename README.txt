СИСТЕМА ЗА СКЛАДОВА НАЛИЧНОСТ

Описание:
Проектът представлява проста система за управление на складова наличност.

Функционалности:
- Добавяне на продукт
- Изтриване на продукт
- Преглед на всички продукти

Използвани технологии:
- Python 3

Стартиране:

1. Отворете терминал в папката на проекта.
2. Изпълнете командата:

python main.py
или
py main.py

3. Следвайте менюто на екрана.

Структура:

models.py
Съдържа класа Inventory и неговите методи.

main.py
Създава обект от класа и управлява потребителското меню.

requirements.txt
Съдържа използваните библиотеки.
